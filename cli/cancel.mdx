---
title: Cancel
description: Stop a queued, booting, preparing, or running job.
---

```bash
compute cancel <run_id>
```

You can cancel while the run is `queued`, `provisioning`, `booting`, `preparing`, or `running`.

Minutes already started on a ready machine still appear on the receipt. Cancel does not unwind prepaid credit you already spent.

If the provider machine is still listed after a cancel, wait for teardown. `compute machines` shows live boxes tied to your account. Do not SSH — there is no customer SSH.
