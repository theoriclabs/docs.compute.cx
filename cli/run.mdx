---
title: compute run
description: Create one run on a fresh machine. Default is fire-and-forget.
---

```bash
compute run path/to/file.py::fn --gpu H100-SXM --wait
```

The entry point is `file.py::function_name`. The function must return JSON-serializable data.

## Flags that matter

| Flag | What it does |
|---|---|
| `--gpu SKU` | `H100-SXM`, `H100` (alias), `MI300X`, or `auto` / `fastest` / `cheapest` |
| `--provider` | `runpod` or `hotaisle` — pin the catalog when a SKU exists on one side |
| `--dry-run` | Print the packed file set. No upload, no run, no charge |
| `--wait` | Stream logs until the run finishes |
| `--yes` | Skip confirmation |
| `--timeout N` | Execution timeout in seconds. Default **600** (10 minutes). Max **86400** (24 hours) |
| `--args '{...}'` | JSON object of keyword arguments for the function |
| `--json` | Machine-readable CLI output |

Default without `--gpu` follows the `@app.function(gpu=...)` decorator, or Hot Aisle **MI300X** if the decorator is silent. For public self-service, pass **`--gpu H100-SXM`** explicitly.

## After create

```bash
compute runs list
compute runs status <run_id>
compute runs result <run_id>
compute runs receipt <run_id>
```

Cancel with `compute cancel <run_id>`. Follow logs with `compute logs <run_id> --follow`.

The dashboard lists the same runs. It does not start them.
