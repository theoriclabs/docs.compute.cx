---
title: Logs
description: Text or JSONL. Follow until the run is terminal.
---

```bash
compute logs <run_id>
compute logs <run_id> --follow
compute logs <run_id> --format jsonl
```

`--follow` / `-f` streams until the run reaches a terminal status.

`--format text` is the default. `--format jsonl` is the same stream as `GET /v1/runs/:id/logs?format=jsonl`.

Logs are kept with the run for **30 days**, then deleted. Do not treat Compute as the only copy of output you care about.

The CLI does not print your source, secrets, or API keys in log output.
