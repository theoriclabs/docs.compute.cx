---

```bash
compute credits
compute credits add 10
```

`credits` prints the spendable balance. `credits add` opens Stripe Checkout for WOW21, Inc. The amount is in **dollars**. The minimum is **$10**.

You can also top up on [Credits](https://compute.cx/credits).

## How spend works

- You pay before the run, not at the end of the month.
- Usage is metered in **started machine minutes** after the box is ready.
- A machine that never becomes ready is **$0**.
- The locked provider rate plus the platform fee are on the receipt. Fee tiers live on [pricing](https://compute.cx/pricing) — do not copy a percentage from an old post.

```bash
compute usage
compute usage --month 2026-08
compute runs receipt <run_id>
```

There are no automatic refunds. If a charge looks wrong, keep the **run id** or **request id** and write [privacy@theoric.com](mailto:privacy@theoric.com) (billing questions can use the same inbox until a dedicated support address exists).
