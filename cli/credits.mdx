---
title: Credits
description: Prepaid USD. $10 minimum Checkout. Balance is after the webhook, not at tab-open.
---

```bash
compute credits
compute credits add 10
```

`add` opens Stripe Checkout. Minimum is **$10**. After you pay, wait for the webhook and re-check `compute credits`. A pending Checkout does not add spendable balance.

The [dashboard credits page](https://compute.cx/credits) shows the same ledger.

## How spend works

You buy credit first. A run is refused if the hold would exceed remaining credit or a spend cap.

Billing is **started minutes** while the machine exists, plus the platform fee on that usage. Failed boots that never start the machine are **$0**. See [Billing](/billing).

Do not copy a fee percentage from this page. Use [Pricing](https://compute.cx/pricing) and `compute runs receipt <run_id>`.

## Usage

```bash
compute usage
```

Per-run lines: GPU minutes, platform fee, total.
