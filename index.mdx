Compute runs a Python function on a **new** cloud GPU, streams output to your terminal, then confirms the machine is gone.

You do not keep a box running between jobs. There is no idle pool. The dashboard shows keys, credit, and past runs — it does not launch work.

<Info>
  Early access. Public GPU self-service starts with **RunPod Secure H100-SXM**. **MI300X** (Hot Aisle) is limited. Admission, concurrency, and spend are capped. This is not an SLO.
</Info>

## What you do

1. Install the CLI from [compute.cx](https://compute.cx/quickstart).
2. Sign in in the browser (`compute setup`).
3. Add prepaid credit (`compute credits add 10` — $10 minimum).
4. Run a function: `compute run train.py::main --gpu H100-SXM --wait`.

The [quickstart](https://compute.cx/quickstart) is the three-command funnel. This site is the manual.

## What a run is

| Step | What happens |
|---|---|
| Pack | The CLI selects the source files your entry point needs and shows them on `--dry-run`. |
| Create | Compute stores the payload, checks your balance, and queues one run. |
| Provision | A fresh 1× machine is created at the **rate locked when you requested it**. |
| Execute | Your function runs. JSON in, JSON out. |
| Finish | You get a result and a receipt. Compute confirms the provider machine is terminated. |

Default timeout is **10 minutes** (max 24 hours). A machine that never becomes ready costs **$0**.

## GPUs you can ask for today

| SKU | Provider | Notes |
|---|---|---|
| `H100-SXM` | RunPod Secure | Public launch SKU. `--gpu H100` maps here. |
| `MI300X` | Hot Aisle | Early access. Stock can be unavailable after rapid recycle. |

Rates change. Trust `compute gpu list` and [pricing](https://compute.cx/pricing), not a number copied from a blog post.

## What this manual does not cover

These exist in the product or the roadmap, but they are **not** part of the public v0.1 story:

- Installing from PyPI (`pip install compute`) — use `curl \| sh` for now.
- Detached SDK handles, persistent disks, custom images, or multi-GPU shapes.
- Checkpoint resume, named secrets as a first-run requirement, or a public REST playground.

If a command is in `--help` but not here, treat it as unsupported until this site says otherwise.
