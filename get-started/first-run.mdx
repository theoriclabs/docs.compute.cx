---
title: First run
description: Pack a function, confirm the file set, then wait on one H100-SXM.
---

You need the CLI installed, `compute setup` done, and at least **$10** of prepaid credit. Add credit with `compute credits add 10` or on [Credits](https://compute.cx/credits).

## 1. Write a small function

Save this as `train.py`. JSON in, JSON out. The function must be importable as `train.py::main`.

```python
def main(steps: int = 40) -> dict:
    import torch
    import torch.nn as nn

    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = nn.Sequential(nn.Linear(16, 32), nn.ReLU(), nn.Linear(32, 2)).to(device)
    opt = torch.optim.Adam(model.parameters(), lr=1e-3)
    loss_fn = nn.CrossEntropyLoss()
    x = torch.randn(256, 16, device=device)
    y = (x.sum(dim=1) > 0).long()
    last = None
    for _ in range(steps):
        opt.zero_grad()
        last = loss_fn(model(x), y)
        last.backward()
        opt.step()
    return {
        "ok": True,
        "device": str(device),
        "steps": steps,
        "loss": float(last.detach()),
    }
```

Compute packs the files your entry point actually imports. You do not upload a whole repo unless those files are reachable from the function.

## 2. See what will upload

```bash
compute run train.py::main --gpu H100-SXM --dry-run
```

`--dry-run` prints the exact file set. It does not upload, create a run, or spend credit.

## 3. Run and wait

```bash
compute run train.py::main --gpu H100-SXM --wait
```

`--gpu H100` means the same machine as `H100-SXM` (RunPod Secure). `--wait` streams logs until the run is terminal, then prints the result.

Without `--wait` the CLI exits after create. Follow later with `compute logs <run_id> --follow`.

Add `--yes` to skip the confirmation prompt (CI).

## 4. Read the receipt

```bash
compute runs receipt <run_id>
```

A machine that never becomes ready is **$0**. Started minutes on a ready machine are billed at the rate locked when you requested the run, plus the platform fee on [pricing](https://compute.cx/pricing).
