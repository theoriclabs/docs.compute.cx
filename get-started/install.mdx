---
title: Install
description: One curl installs an isolated CLI. PyPI is not the v0.1 path.
---

Supported: **macOS and Linux**, Python **3.10–3.14**.

```bash
curl -fsSL https://compute.cx/install.sh | sh
```

That script creates an isolated environment, installs one released wheel from `https://compute.cx/releases/`, and puts `compute` on your `PATH`.

Confirm:

```bash
compute --version
compute doctor --json
```

`doctor` reports client version, API reachability, and whether you are signed in. It never prints tokens, source, or local paths.

## Upgrade

Re-run the same install command. It replaces the previous isolated install.

## What not to do

- Do **not** `pip install compute`. That route is not the v0.1 release.
- You do not need a git checkout of this product to run jobs.
- Windows is out of scope for the CLI.
