WOW21, Inc. sells prepaid Compute credit through Stripe. Minimum top-up is **$10**. There is no monthly invoice and no automatic card charge when a cycle ends.

## What you are billed for

| Situation | Charge |
|---|---|
| Machine never becomes ready | **$0** |
| Machine is ready | Provider list rate **locked at request time**, counted in started minutes, plus the platform fee |

The platform fee is marginal and depends on month-to-date provider usage. **Read the current tiers on [pricing](https://compute.cx/pricing).** This manual does not reprint a percentage so an old docs page cannot disagree with the biller.

## Where to look

```bash
compute credits
compute usage
compute runs receipt <run_id>
```

Dashboard: [Credits](https://compute.cx/credits) and [Usage](https://compute.cx/usage).

No automatic refunds. Exceptional credits are manual. Include a **run id** or **request id** when you write.
