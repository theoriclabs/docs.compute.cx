Email [privacy@theoric.com](mailto:privacy@theoric.com) for account, billing, and privacy requests. Include:

- Your Compute user id (`usr_…`) or the email on the account
- The **run id** (`run_…`) and/or **request id** (`req_…`) from the CLI error footer or `compute doctor --json`

Do not paste session tokens, API keys, device codes, or secret values. Do not attach packed source unless we ask.

There is no public issue tracker for this product yet. Do not file Compute bugs on a random GitHub repo.

Privacy and deletion: see the [privacy policy](https://compute.cx/privacy).
