# docs.compute.cx

Customer manual for Compute. Mintlify publishes this repo to https://docs.compute.cx.

Connect the Mintlify GitHub App to **this** repository only. Do not install it on `theoriclabs/compute.cx`.

After the App is connected: `mint add-domain docs.compute.cx`, add the printed TXT records, then CNAME `docs` → the Mintlify target via `namecheap`.
